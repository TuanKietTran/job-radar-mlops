Salary tools

Calculators for Vietnam gross to net salary, unemployment benefit estimates, and social insurance. Rates are 2026 assumptions dated 2026-11-14. Re-check rates against the law in force before using results for a real payroll decision.

Checking salary API status.

  • Gross to net calculator - net salary, insurance, and tax from gross salary, or gross salary from net salary.
  • Unemployment benefit calculator - estimated benefit months and amount from months contributed and average salary.
  • Social insurance calculator - BHXH, BHYT, and BHTN from gross salary.

These pages call the salary API at http://127.0.0.1:8001. Start the stub server from tests/tools/stub_salary_api.py for local testing. The stub is for local testing only and is not the real engine.
